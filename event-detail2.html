👨‍💻 Tech Week Special

Software Engineering Week

Dive into the world of clean code, system design, and career paths in software engineering.

📅 August 12–16, 2025
📍 Auditorium B
← Back to Events / Software Engineering Week

🧠 Event Description

Software Engineering Week is a 5-day journey into the latest practices, tools, and technologies used by professional software developers. Attend engaging talks, hands-on coding labs, and interactive Q&A panels with engineers from leading companies.

The event is perfect for students who want to sharpen their skills in backend, frontend, DevOps, testing, and software architecture.

Participants will build real projects, receive personalized feedback, and connect with recruiters from the tech industry.

💡 What You'll Learn

Coding Interview Prep

Tips and mock sessions to ace your interviews
